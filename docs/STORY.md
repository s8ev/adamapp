# STORY（制作向け・全編ネタバレ）

## 世界

汐継市。災害避難のための音声中継網《継電》が、事件の証言記録も保管している。
運営会社オルドは時刻署名を書き換え、暴動の責任を住民へ転嫁してきた。
記憶を物理的に書き換える超能力は存在しない。薬物、録音の編集、偽の任務記録で人を誘導する。
主人公レイは署名無効化手順《NULL》を設計した配線技師。過去の封鎖作戦に加担した。
負傷と鎮静剤で封鎖当夜の記憶が途切れているが、技能は残っている。

## 時系列の真相

1. レイとナギは避難用中継網を作る。署名を消せる保守手順に危険を認識していた。
2. オルドが住民の証言を改ざん。レイは強要されて封鎖命令に署名し、多数が取り残される。
3. 記録係トワは改ざん前の原本を退避。警備兵イサも原本の受領を目撃する。
4. ナギは遺族として怒り、全記録の抹消と幹部の殺害を計画。住民の証言も消えると知っている。
5. 負傷したレイを助けたナギは、最終解除に本人の生体署名が必要なため同行する。
6. 本編。レイは最初「過去を消せば救われる」と思わされるが、記録を残す選択を獲得する。

## 開示と伏線

| 場面 | 初見の意味 | クリア後の意味 | 裏付け |
| --- | --- | --- | --- |
| M01 ナギ「あなたの声でなきゃ、開かない」 | 本人確認の助言 | 最終鍵として利用している | M07署名仕様書 |
| M02 救援無線の三拍の無音 | 通信障害 | 編集した命令の継ぎ目 | M04監視音声 |
| M03 ナギ「暗いほうが、記録は正直」 | 消灯パズルのヒント | 自分も監視を避けている | 隠し室の稼働ログ |
| M04 資料に二人分の承認印 | 協力者がいた | 主人公にも責任がある | M07封鎖命令 |
| M06 ナギが最後の避難者数を言い直す | 心配して数え直した | その場を見ていない時刻の数を知る | イサの証言 |

正体を夢・幻覚で取り消さない。ナギの救助は本物で、信頼できる行動と隠された目的が共存する。
M02の遠隔消火、M05の扉開放、M06の支援射撃を実際にプレイヤーの救命として見せる。

## 各章の物語

M01: 目覚め。自分の声の封鎖放送が流れる。ナギと合流せず無線で脱出。
M02: 中継列車で追跡。命令の録音に無音の継ぎ目。救援は本物。
M03: 消灯すると改ざん前の配線記号が読める。隠し室はナギの私設端末。
M04: 記録庫。秘密資料とトワ。救出または殺害は状況を示して選ばせる。
M05: 搬送路。トワを救っていれば短い証言、死亡なら残された録音で必須情報を保障。
M06: 通信塔包囲。投降したイサを見逃せる。戦闘能力を奪っても殺さず進行可能。
M07: 自分の署名を確認。ナギへ「原本を見た」/「何もなかった」の重要選択。
M08: 管制官セキを倒し、中継核の処理（公開/消去/隔離）を選ぶ。
SECRET: 条件成立時、脱出画面に見せた暗転からナギの「……その原本は、残せない。」。
ナギの救助無線と同じ三拍を攻撃予告に転用。既存作品の決め台詞を流用しない。

## フラグ契約（PHASE 7実装）

`found_secret_file`, `found_hidden_room`, `saved_target`, `killed_target`,
`trusted_partner`（初期true）, `lied_to_partner`, `spared_enemy`,
`final_boss_defeated`, `secret_boss_defeated`, `evidence_action`（unset/broadcast/purge/isolate）。
救出と殺害は相互排他。story_flagsを直接書き換えず、イベントを検証して変更する。
M07で原本を見たと告げるとtrusted_partner=false、隠すとlied_to_partner=true。
会話選択には先行する証拠が必要。持っていない証拠の告白選択は出さない。

裏ボス条件S:
`found_secret_file && found_hidden_room && saved_target && spared_enemy &&
(!trusted_partner || lied_to_partner)`。
条件の各情報には2種類以上のヒントを配置し、隠しフラグの総当たりを求めない。
SはM08のボス後に一度だけ評価。通常結末へ遷移する前にチェックポイントを保存する。

## エンディングの一意な解決順

| 優先 | 条件（通常ボス撃破必須） | 結末 |
| --- | --- | --- |
| 1 | S成立、裏ボス未撃破 | 裏戦へ進む。まだエンディングを確定しない |
| 2 | S成立、裏ボス撃破、broadcast、saved_target | TRUE — 証言と自身の責任を公開し、トワと残る |
| 3 | S成立、裏ボス撃破、その他の処理 | BETRAYAL — ナギを退けたが証言を社会へ返さず孤立 |
| 4 | S不成立、killed_target または purge | BAD — 改ざんと同じ消去を繰り返し、命令放送が再開 |
| 5 | S不成立、上記以外 | NORMAL — 都市から脱出。ナギの計画の全容は不明 |

死亡はどの戦闘でもリトライであり、BADの条件にはしない。
TRUE到達にはS、broadcast、裏戦勝利が必要。BETRAYALはS＋isolateでも再現できる。
全結末後にチャプター選択と既読ログを開放。2周目限定で意味の変わる小さな観察文を置くが、
TRUEに周回は強制しない。セーブ世代移行で新フラグ追加時の既定値を明示する。
