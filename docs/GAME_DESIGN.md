# GAME DESIGN — 残響回線 / NULL RELAY

状態: PHASE 0の設計基準。以下のゲーム内容は未実装。実装の事実はROADMAPを参照。

## 体験の核

雨の工業都市で、自分の声が残る偽造記録を追う配線技師レイ。
動きを止めずに射線を組み替え、敵の武器と設備を利用し、自分の意思で記録を残す。
ジャンルは横視点2Dアクション、銃撃、近接、探索、短い会話、環境パズル。
仮題は商標・ストア名の確認前。キャラクター、世界、台詞、素材は本作専用に制作する。

## 採用判断

横視点によりジャンプ、壁蹴り、スライド、縦方向の射線を同じルールで成立させる。
俯瞰視点と3Dは採用しない。通常移動は速い走行、歩行キーの強制はしない。
プレイヤーを弱くして難度を稼がず、敵の予告、地形、装弾数、移動経路で選択を作る。
ハンドガン＋近接だけでも全基本敵を倒せる。スキルツリー、クラフト、ランダム装備は作らない。

## ゲームループ

20–45秒の戦闘→安全な呼吸→10–25秒の会話/発見→異なる射線の戦闘。
一部屋の目標と出口をすぐに読める構図にし、血・ライト・背景より人物輪郭を優先する。
死亡後は直前の戦闘開始状態へ1秒以内の再試行を目標にする。台詞の再視聴は強制しない。
落下やリソース枯渇で進行不能にしない。落下復帰点、予備武器、パズルのリセットを設ける。

## 尺と密度

本編目標: 8章合計約60分（各章の想定はLEVELS）。探索と裏戦で60–90分。
この数字は設計目標であり、実測値ではない。M01の初見テストで部屋数と時間を校正する。
同じ戦闘構成は続けて2室まで。連続した同種の内容を10分超継続させない。
必須会話は1場面20–35秒を基本上限。任意ログと選択場面は別にする。

## コアルール

- ライフ3区画を初期案とし、回復は明示的な休息点。被弾無敵0.65秒を初期値とする。
- 銃2枠＋近接1枠。弾倉と携行弾を別管理。拾得で前進し続けられる配置にする。
- 回避は短い無敵、ダッシュは移動と再配置、スライドは低姿勢として用途を分ける。
- リロード、フィニッシャーは危険を伴う選択。強制演出で操作を長時間奪わない。
- 信頼・証拠・救命はシナリオフラグへ。スコアの高低で物語を罰しない。

## 完成時の画面

TITLE: CONTINUE / NEW GAME / LOAD GAME / SETTINGS / CHAPTER SELECT / CREDITS / QUIT。
PAUSE: RESUME / RESTART CHECKPOINT / OPTIONS / RETURN TO TITLE。
GAME OVER: RETRY / LOAD / TITLE。確認は新規開始で進行を上書きする時だけ。
最初のセーブがないCONTINUEは無効理由を表示。クリア済み章はチャプター選択で再訪。
チャプター再訪は本編セーブと別スロットで行い、後半のフラグを持ち込んで結末を捏造しない。

## 非交渉の品質

通常画面の3Dゼロ、全素材の出典記録、字幕の視認性、FPS非依存、即時入力、
取り返せない操作の明示、セーブ破損からの復旧、全エンディングへの再現可能な到達経路。
販売品質の判断はPHASE 16の実機・初見QAで行い、起動だけで完成扱いしない。
