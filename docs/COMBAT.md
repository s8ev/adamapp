# COMBAT

状態: 初期調整案。PHASE 2–5の試験で数値を確定する。すべて秒・px/s単位。

## 入力と移動

| 行動 | 初期キー | 制約・目的 |
| --- | --- | --- |
| 走る | A/D | 最高220px/s、加速1800px/s²、停止2400px/s² |
| 狙う / 撃つ | マウス / 左ボタン | 移動と並行。狙いを描画ごとに更新 |
| ダッシュ | Shift | 520px/s、0.12秒、再使用0.45秒。無敵なし |
| 回避 | Alt | 0.24秒、前半0.10秒のみ無敵、再使用0.70秒 |
| スライド | Ctrl またはS | 速度維持して低姿勢、0.50秒上限。低天井で立たない |
| ジャンプ / 壁蹴り | Space | 初速-370px/s、重力1100px/s²、入力バッファ0.10秒、コヨーテ0.09秒 |
| 近接 | 右ボタン | 武器別の発生・持続・硬直。銃弾の万能反射はしない |
| リロード | R | 弾倉保存方式。途中キャンセルで弾を増やさない |
| 切替 | Q / 1 / 2 | Qは循環。射撃タイマーを切替でリセットしない |
| 取得 / 奪取 / 会話 | E | 画面に提示した最優先対象のみ。奪取は怯み中・近距離 |

| フィニッシャー | F | 崩れた敵への短い専用入力。誤って会話を殺害へ転用しない |
| ポーズ | Esc | 入力解放待ち、解除直後の誤射防止 |

ゲームパッドはPHASE 2から入力の抽象化を維持し、PHASE 16で完成可否を判断する。
KB+Mの完成を優先。ダッシュ中の射撃、走行→スライド→武器奪取をシームレスにつなぐ。
ジャンプ中もリロード可能。壁蹴りの同壁連打には短いロックを設け、入力を握り潰さない。

## 実装責務

PlayerController: 運動と状態遷移。WeaponSystem: 装備/弾薬/射撃。
DamageSystem: HitContextの確定、死亡は一度だけ。FeedbackDirector: 音とカメラ/時間演出。
アニメから判定を逆算せず、状態のイベントからアニメと判定を駆動する。
最小HitContext: source_id、team、world_hit、direction、hit_zone、weapon_id、damage、
impulse、source_velocity、target_velocity、target_stance、surface_tag、nearby_obstacle。
受信者へのダメージ適用後に血・音・スコアへ通知。各演出がライフを変更しない。

## 射撃と公平性

高速弾はphysics tick間の線分cast。貫通回数と材料を検証し、薄壁抜けを事故で発生させない。
敵の初弾には0.35秒以上の視覚/音予告。画面外から即着弾しない。
ドア通過後0.25秒は敵の初射撃猶予。リトライ直後も同条件。上手さを削る追尾弾は避ける。
敵弾で解くパズルには安全な遮蔽と撃ち直しを用意する。
カメラは進行方向に先読みし、走行時でも敵の予告を視界に入れる。

## 死亡演出合成

頭/胴/脚の3部位、立ち/屈み/空中の姿勢、左右と上下の衝撃を基本素材へ合成。
銃撃の反り返り、脚崩れ、散弾吹き飛び、斬撃、鈍器回転、空中落下を基本6系統とし、
近い壁の衝突、段差からの転落、家具破片、床摩擦で着地を変える。
頭部・胸・骨盤・四肢の2D関節点を速度制限付きで補間。無制限ラグドールは使わない。
死亡後1.2秒程度で静的な死体へ。死亡判定と血/物理を切り離して負荷を制限する。
素材と姿勢だけをランダム化せず、HitContextに沿う。固定seedで問題を再現できるようにする。

血は方向付き空中粒、床/壁デカール、武器汚れ、短時間の血足跡、死体の溜まりに分離。
初期上限: 活動粒512、動的死体12、部屋デカール96。古いものからフェード。
Blood=0で無効。床の操作対象と敵輪郭の上に血を描かない。

## 演出の上限

ヒットストップ: 軽打0.025秒/重打0.05秒、連打で累積しない。UIと入力収集は停止しない。
スローは専用TimeControllerだけが扱い、ポーズ/死亡/遷移時に必ず戻す。
シェイク0–100%、明滅OFF、色収差OFFを設定可能にする。血で受撃部位を隠さない。
光と粒は低解像度上で描く。フラッシュを切っても音、輪郭、姿勢で被弾を伝える。
