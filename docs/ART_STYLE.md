# ART STYLE

## 画面の契約

完全2D。背景、人物、UI、文字、血、光の素材、カットシーンもピクセル基準。
内部640×360、tile16×16、人物24×40、ポートレート48×48。
720p=2倍、1080p=3倍、1440p=4倍、4K=6倍。Nearest、整数拡大、アスペクト維持。
非整数サイズは黒帯を使う。カメラの滑らかな物理補間と最終描画のピクセル化を両立する。
3Dモデル/3D背景は使用しない。写真を縮小しただけの背景は完成素材にしない。

## 色と構図

背景 #080F1B / #122231 / #203645。味方/情報 #69DDCE。
主人公/操作 #F4B86A。敵の危険 #FF647F。文字 #D9E7E5、補助 #8FA8B5。
高彩度は画面面積の20%以下を目安。血は暗い臙脂にし、敵の予告の赤と明度を変える。
前景は濃いシルエット、移動床は細い縁光、奥景は低コントラスト。
汐継市の識別要素: 細い中継線、琥珀の保守灯、青緑の蓄電槽、雨除けの斜め板。

## アニメ・FX

移動8方向を無理に描かず横視点の左右を基本に、銃腕だけ狙い角を分ける。
走り8枚、ジャンプ/着地、滑り、壁蹴り、回避、部位別怯みを制作。速度に足運びを追従。
残像・血粒・薬莢は整数サイズ。FXは内部解像度で合成し、HDの滑らかな図形を混ぜない。
限定的な2Dライト、短いヒットストップ、リム光で現代的な密度を出す。
画面歪み、色収差、衝撃波は任意設定で無効化可能。台詞と照準の上に歪みを重ねない。

## UIとフォント

DotGothic16の16pxを基本。2倍見出し32px。アンチエイリアスとMSDFを無効。
12pxへの縮小や小数位置を避ける。字幕は16px、2–3行、640px内で日本語30字以下/行。
長文を縮小せずページへ分ける。フォーカス、色、形の3つで選択を示す。
パネルは矩形と1px線。操作対象は最低24px高を目標。背景の明滅は字幕の下で停止。

## 制作と完成判定

素材にauthor/source/license/statusを台帳へ。graybox→art→reviewedを区別する。
M01完成時にM01のgraybox素材をゼロにする。全編完成時に全章の仮素材をゼロにする。
現在の起動背景は本作用のコード描画によるピクセル図形。ゲーム背景一式の完成とはしない。
AI画像を利用する場合はサイズ/パレット/アルファ/輪郭を統一して再確認する。
