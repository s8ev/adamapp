# AUDIO

Master/Music/SFX/UI/Ambienceのバス、Master/Music/SFXの音量・ミュートを実装済み。
音素材、再生システム、重要SEの優先度制御は未実装。
SFXはUIと環境音も親としてまとめ、Masterだけで全音が下がる構造にする。

| 系統 | 方針 | 検証 |
| --- | --- | --- |
| 銃 | 初動の短い音＋機械音＋室内尾音。武器ごとに音域と長さを変える | SMG連射で飽和しない、排莢と発砲時刻一致 |
| 近接 | 空振り、肉、装甲を分ける。刀は乾いた切断音 | ヒットストップでも二重再生しない |
| 血/死体 | 低い着地音、過剰な高音を避ける | 発砲予告を埋めない |
| 足音 | 金属/濡れた床/コンクリート。歩調と同期 | AI向けNoiseEventと聴こえる範囲を説明可能にする |
| UI/会話 | 短いクリック。文字音は毎文字鳴らさず40ms以上間隔 | 長い日本語で疲れない、会話速度による音の暴走なし |
| 環境 | 雨、中継機の唸り、遠い放送 | 方向と距離で空間が読める |
| BGM | 独自の低音パルスと金属打音。戦闘レイヤーを小節で切替 | 継ぎ目、ループ、死亡復帰でノイズなし |
| ボス | セキは規則正しい拍、ナギは救援信号の三拍を崩す | 予告の三拍はBGMをduckして聞かせる |

M07は意図的にBGMを止める。重要な証言を話すときは銃撃を止める安全区間を作る。
発音数の初期上限32。発砲、敵の予告、被弾を足音や薬莢より優先。
音量0ではミュート。音を切っても視覚の予告と字幕で進行できる。
外部曲の流用はしない。完成素材は独自制作または許諾確認済み素材のみ。
